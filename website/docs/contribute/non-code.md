# Non-code contributions

You can help without writing Ruby or running Docker.

- **Docs and wording** — fix typos, clarify install or integrator pages, and open a Merge Request when the change lives in this repo ([First contribution](/contribute/first-contribution) covers the MR flow).
- **Check and clarify issues** — reproduce reports, add missing steps, link related issues on [GitLab](https://git.octree.ch/decidim/vocacity/decidim-modules/decidim-module-rest_full/-/issues).
- **Welcoming comments** — leave a short, kind note on open issues so newcomers know someone read them.
- **Translations** — join Crowdin; see [Translations](/contribute/translations).

Conduct: repository [CONTRIBUTING.md](https://git.octree.ch/decidim/vocacity/decidim-modules/decidim-module-rest_full/-/blob/main/CONTRIBUTING.md) (Code of Conduct). Not sure where to start? [Ways to contribute](/contribute/ways-to-contribute).
