# Translations

Translate RestFull through **Crowdin only**. Do not open GitLab Merge Requests that only edit locale YAML for humans—CI downloads Crowdin translations into the gem locale files.

Join the Crowdin project for this repository. Maintainers publish Crowdin access via the project; if you need an invite, ask on a [GitLab issue](https://git.octree.ch/decidim/vocacity/decidim-modules/decidim-module-rest_full/-/issues).

No Ruby is required. You translate **RestFull strings** in Crowdin (system UI text, permission labels, and related gem text)—not Decidim core UI.
